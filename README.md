# Cloud Networking & Biblical Language Data Analysis Project  
## Enhancing NT Greek & BiblePlotter Scripts for Expanded Linguistic Analysis of Biblical Love References

This project combines cloud networking exploration with advanced script modification and biblical language data analysis to improve how scriptural references to “love” are identified, categorized, and analyzed.

The primary focus of this repository is the enhancement of existing **NT Greek** and **BiblePlotter** files to expand lexical recognition, improve parsing methodologies, and increase the contextual variety of love-related references found throughout biblical texts. By refining source data structures and improving script logic, this project transforms limited keyword analysis into a broader and more insightful theological and linguistic research tool.

This repository demonstrates technical problem-solving through:
- Script optimization
- Data parsing
- Text analysis
- Version control
- Documentation
- Process improvement

It serves as both a research-oriented project and a technical portfolio piece, showcasing skills transferable to cloud engineering, data analytics, automation, and systems optimization.

---

## Project Purpose
The goal of this project is to:
- Improve biblical language analysis through expanded NT Greek lexical detection
- Increase the diversity of “love” references identified in scriptural datasets
- Optimize BiblePlotter datasets for broader verse categorization and analysis
- Strengthen data processing workflows for repeatable research
- Demonstrate technical growth through independent repository development
